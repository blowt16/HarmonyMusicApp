00 / QUICK VERDICT

先给结论

如果你想要“清新、简洁、主流、好实现、答辩好讲”，首选 方案 A：原生清透。它不是凭空造风格，而是把华为音乐和 QQ 音乐鸿蒙版里最稳的部分，收敛成 wyyhm6 能直接使用的规则；播放页再叠加 C 的沉浸处理，形成一个主次分明的产品。

推荐组合

A 原生清透 + 播放页 C 沉浸

暖白背景、白色圆角卡片、单一珊瑚红强调色、大封面留白、底部悬浮 mini player。与当前 wyyhm6 的白色底和 Hds 组件最接近，改造量最小，也最符合“色彩统一、界面美观”的课程要求。

A原生清透 · 推荐 B晨光渐变 C沉浸黑胶 D极简黑白
这次先不改代码。看完本页后，回复你选择的字母和是否需要“播放页沉浸”，我再进入页面级设计和实现。
WHY A

最少的返工，最高的完成度

现有界面已经是白底 + 珊瑚色，直接做减法就能统一；登录、四 Tab、收藏、我的、服务卡片都能沿用这套语言。

另一个选择

如果你更想要“年轻、设计感”，选 B 晨光渐变；如果愿意为高级感冒一点“空”的风险，选 D。

01 / EVIDENCE

先看真实产品，而不是先画风格

下面都是实际应用界面截图。重点不是“哪个最好看”，而是找出它们为什么看起来干净、我们能不能在 ArkUI 里低成本复现。

强品牌蓝功能入口多多端联动不建议照搬

鸿蒙社区播放器 · 学生项目参考

IT营社区 / 2024

淡紫背景、白色列表、封面和操作入口清晰。它没有炫技，但信息结构完整、实现成本低，最接近“课程项目可以自己讲明白”的程度。

列表清晰轻量白卡实现简单适合课程

视觉共性

浅色底 + 大图/大标题 + 一处强调色。深色页面通常只出现在播放或氛围场景，不抢主界面。

结构共性

底部 3–4 个 Tab，配悬浮 mini player；首页用 2–3 个纵向 section；列表行高足够，封面是主要识别点。

课程落点

WY 需要补到 4 个 Tab、欢迎、登录、个人中心和服务卡片。不要为了“高级”牺牲可演示性。

当前 wyyhm6 的实际界面

这是在 Pura 90 Pro 模拟器上的真实截图。它已经有不错的底子：白底、彩色封面、底部 3 Tab 和 mini player；主要问题是“我的”还是内容页而不是个人中心，且缺少欢迎、登录、第 4 个 Tab 和服务卡片。

现状：白底 + 珊瑚红现状：3 Tab现状：播放页氛围较强目标：4 Tab + 个人中心
02 / DIRECTIONS

四种可落地的方向

不是四套“皮肤”，而是四种信息取舍。A、B 适合整站；C 更适合播放页/详情页；D 最挑内容，做得克制会高级，做不好会显得空。

A

原生清透

暖白、轻阴影、单一珊瑚红；最接近 wyyhm6 现状，适合整站。

改造量：低 · 推荐

分割
  • 圆角：卡片 20–24vp，封面 16vp，胶囊 999vp。
  • 字体：HarmonyOS Sans SC；大标题 30–34 粗体，正文 15，辅助 12。
  • 阴影：只给浮层和主卡，`rgba(31,25,20,.06)`，不要每张卡都投影。
  • 间距：4/8 网格；页面左右 16–20vp；section 间距 24–32vp。

页面规则

  • 首页：顶部问候 + 搜索入口；一张接近半屏的精选主卡；下面是“为你推荐 / 最近播放 / 精选歌单”三段。
  • 搜索：胶囊输入框 + 历史标签 + 结果列表；不要一屏塞满筛选器。
  • 收藏：收藏 / 最近播放两个 segment；空态给明确引导。
  • 我的：头像 + 昵称 + 登录状态；收藏数、历史数；设置和退出登录。
  • 播放页：可切到 C 的深色封面氛围，但主站保持浅色。
推荐理由：当前 wyyhm6 已经使用白底 + 珊瑚色，HdsTabs 也能直接承载 4 个 Tab；这套方案不需要重写导航，最容易在 11 月 1 日前完成并稳定演示。
B

晨光渐变

淡紫到暖橙的柔和渐变，白色圆角卡片，绿色播放按钮。

强调
  • 背景只允许两个相邻色相，避免“彩虹”。
  • 白卡透明度保持 100%，文字对比要过 4.5:1。
  • 绿色只做播放/选中，不再加第二个品牌色。

适合与风险

  • 适合：想让 App 看起来更年轻、更有“生活方式”感。
  • 风险：现有封面颜色很杂，渐变底容易和封面打架；需要给封面统一加白边/遮罩。
  • 比 A 多做一层主题背景和色彩适配，工作量略高。
C

沉浸黑胶

深色底 + 封面色氛围 + 大唱盘/大封面，歌词和播放控制成为主角。

强调
  • 背景从封面提取主色，叠 65%–80% 黑色遮罩保证文字可读。
  • 播放器保持一个主行动按钮，其他控制去掉描边。
  • 歌词只显示当前行附近，避免整屏密集文字。

适合与风险

  • 适合：播放详情的“仪式感”，能让答辩演示更有氛围。
  • 不适合：全站深色会让“清新简洁”目标跑偏，也增加对比度和截图难度。
  • 建议：作为 A 的播放页分支；主界面仍使用浅色。
D

极简黑白

无卡片、无阴影、超大字号，封面是唯一的色彩来源；绿色只做播放状态。

强调
  • 只保留字号和留白做层级；列表用细分割线，不用阴影。
  • 封面图必须高质量；没有好图时这套风格会立刻变空。
  • 按钮大而少，文字按钮优先于彩色按钮。

适合与风险

  • 适合：面向设计感、想做出“作品感”的答辩展示。
  • 风险：对内容质量和排版控制要求高；课程 App 有 4 个 Tab、我的、服务卡片，容易显得冷清。
  • 建议：只借鉴它的排版和大封面，不作为整站目标。
我的建议：A 作为整站视觉，播放页使用 C 的深色封面氛围；B 作为备选（更年轻），D 作为局部参考（大字号和极简列表）。这样既能满足“清新简洁”，又能在答辩时用播放页做出“哇”的效果。
