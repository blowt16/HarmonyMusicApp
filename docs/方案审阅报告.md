## 一、必须补齐的 9 个点

### 1. 音频和 Ability 的所有权要重新划清

现在 `EntryAbility` 负责音频初始化，并在 `onDestroy` 销毁音频会话；改成双 Ability 后，登录成功会 `terminateSelf()`，可能把 MainAbility 刚建立的音频会话一起销毁。

必须明确：

- `EntryAbility` 只负责欢迎/登录，不初始化、也不销毁音频；
- `MainAbility` 负责主题、窗口、AudioSession、ImageCache 和播放器；
- `AudioSessionService` 里通知栏点击目标目前写死 `EntryAbility`，要改到 `MainAbility`；
- `backgroundModes: ["audioPlayback"]`、`KEEP_BACKGROUND_RUNNING`、`INTERNET` 的 `usedScene.abilities` 要从 EntryAbility 迁到 MainAbility；
- 退出登录时停止播放、停止后台任务、释放 AVSession，避免“退出后还在后台播放”；
- MainAbility 建议用 `singleton` 启动，并处理 `onNewWant`，避免通知/卡片反复拉起新实例。

不补这一条，双 Ability 会直接影响播放和通知栏，属于阻塞项。

### 2. 服务卡片会绕过登录，且“刷新”验收口径矛盾

方案里写“卡片点击拉起 MainAbility”，但 MainAbility 没有登录校验；如果 MainAbility 不 exported，卡片可能拉不起来；如果 exported，未登录也能进首页。

建议：

- 卡片点击统一拉起 `EntryAbility`，由它检查登录态，再决定去登录还是主界面；
- 卡片做静态 2×2，不做实时刷新；把验收从“刷新正常”改成“添加、展示、点击拉起正常”；
- 如果一定要动态刷新，需要额外实现 `updateForm` 和定时策略，不建议在本次周期内做。

### 3. 深色播放页目前会被全局浅色主题“打回原形”

现有 `PlayPage`、`PlayerControls`、`LyricView`、`HdsNavigation` 都依赖全局文字/强调色 token。全局是浅色主题时，直接给播放页加深色背景，会出现：

- 标题、返回按钮、菜单是黑色，看不见；
- 进度时间和控制按钮是深色；
- 歌词部分用 `isDark ? #CCCCCC : #000000`，浅色主题下歌词直接变黑；
- 音质/播放列表弹层仍是浅色；
- 状态栏图标可能变成黑字黑底。

需要在方案里补一个**局部深色播放器 token 层**：

- 播放页自己的 `playerBg / playerTextPrimary / playerTextSecondary / playerAccent`；
- `PlayerControls`、`LyricView`、弹层接收这些值；
- 页面显示时把状态栏内容切成白色，退出时恢复；
- HdsNavigation 标题和菜单要能切到深色主题，或换自定义顶栏；
- 不要用全局 `setColorMode` 把整站变暗。

### 4. 播放历史和收藏统计不会自动刷新

当前只有 `Index` 的搜索播放和无人引用的 `SearchPage` 写历史；歌单详情、播放页点列表、上一首/下一首、自动切歌都漏写。收藏后返回“我的”，收藏数和列表也不会自动更新。

建议：

- 在 `PlayerService` **成功起播后统一记录一次历史**，覆盖所有入口；
- 收藏/历史/我的统计在 Tab 切回、从播放页返回时重新读取；
- 收藏 Tab 先做“查看+播放+清空历史”即可，不做每行更多菜单，降低工作量。

### 5. 网络异常被吞成“空结果”，用户分不清原因

`ApiService` 没有设置超时，默认可能等很久；异常都变成空数组/空字符串，页面无法区分“断网”“无结果”“接口失败”。`loadMore` 先自增页码再请求，失败重试会跳页。

需要补：

- 连接/读取超时（建议 8–10 秒）；
- 区分“无搜索结果”“网络失败”“接口返回异常”的 UI；
- 分页失败不前进页码，保留已有结果；
- 播放地址为空时由 `PlayerService` 发出错误事件，页面才能 toast/重试；
- 播放 AVPlayer 的 error 回调也要接到 UI，而不是只停在 STOPPED。

### 6. 登录/返回栈还缺细节

需要补充并验证：

- `startAbility` 失败时不能 `terminateSelf()`；
- 登录成功跳 Main 后，EntryAbility 要妥善结束，避免返回键回到欢迎/登录；
- 退出登录要直接进 Login，而不是再走 1.5 秒欢迎页；
- 欢迎页定时器要在 `aboutToDisappear` 清理；
- 卡片/通知启动 Main 时，`onNewWant` 的处理；
- EntryAbility 里 `ThemeManager.addListener` 之后没有 remove，双 Ability 初始化会残留旧窗口回调。

### 7. 品牌资源清单不完整

方案只列了 entry 的 media，但桌面图标来自 `AppScope` 的 `layered_image`；Entry 和 AppScope 都有 `foreground/background`、label，另外还有 `startIcon`、启动背景色、卡片名称。

执行前要统一：

- `AppScope/resources/base/media/*`（layered_image、foreground、background）；
- `entry/src/main/resources/base/media/*`（startIcon、foreground、background）；
- AppScope `app_name`、EntryAbility label、权限说明、卡片 label；
- 旧字符串 `PhiLia`、`网易云音乐` 全部清除；
- `bundleName` 改动后重新安装，旧包不会被覆盖。

### 8. “我的”菜单和设置页没有落点

方案写了四个设置菜单，但现有只有 `SettingsPage` 一个页面，其余页面不存在；“退出”在个人卡和菜单里重复。

建议缩减为：

- 个人卡右上角只保留一个低调的“退出”文字按钮，或只在菜单里放“退出”；
- “设置”进入现有 `SettingsPage`，页面内分三组：播放与音质、外观与背景、关于清听；
- “关于”用弹窗即可，不新建页面；
- 背景图片设置从主“我的”页移到 Settings，默认关闭，避免破坏 A 风格。

报告、视频、提示词、AI 使用日志、截图都挤在最后 1–1.5 天，而且目录里已有的 `系统生成代码提示词.txt` 是新闻 App 旧稿、`讲解视频.mp4` 早于本次二开，**不能直接提交**。

## 二、技术可行性核对

| 问题 | 结论 |
|---|---|
| HdsTabs 加到 4 个 | 可行，当前就是 `TabContent` 结构，没有 3 个的上限 |
| 自定义选中色 | 可行：`BottomTabBarStyle.labelStyle({ selectedColor, unselectedColor })` + SymbolGlyph 颜色；当前硬编码白色需要改 |
| Dark 播放页 | 可行，但必须做局部深色 token，不能只改背景色 |
| 双 Ability | 技术上可行，风险集中在音频所有权、通知目标、返回栈和权限配置 |
| 服务卡片 | 可行，FormExtensionAbility + form_config；静态卡片最容易验收 |
| 未签名 HAP | **本机模拟器实测可安装**（HP/WY 都装过）；真机/正式安装才需要签名。答辩用模拟器则不必因签名卡住 |
| Hds/API 版本 | 当前 SDK 26 能构建；Hds 要求 API 23，不能承诺更老设备 |
| API 可用性 | 实测可搜索/播放，但属于非官方接口，随时可能变更/限流；必须有失败态和兜底 |

## 三、还需要补的设计点

- **首页顶部菜单**：当前有搜索、主题、背景三个入口；4 Tab 已有搜索，建议移除顶部搜索；主题/背景移到设置，避免和 A 风格冲突。
- **深浅色优先级**：建议主界面固定浅色、播放页固定深色；如果保留全局主题开关，必须定义它和播放页深色的优先级。
- **空态/加载态/错误态**：方案已有描述，但还需落到每个页面的具体文案和按钮（重试、清空、去搜索）。
- **SearchPage 去留**：`pages/SearchPage.ets` 没有任何路由引用，却在 `main_pages.json` 注册；建议移出注册并删除，避免两套搜索逻辑。
- **收藏列表操作**：建议只做播放、清空历史、在播放页取消收藏；不要做每行更多菜单。
- **演示数据**：答辩前至少准备 2 首可播放歌曲、2 条收藏/历史，避免现场“我的”全空。
- **无障碍/对比度**：`#E4575F` 配白字只有 3.6:1，达不到方案自定的 4.5:1；按钮/正文强调色改为 `#C8424C`（4.84:1），`#E4575F` 只用于图标/装饰。
- **失败兜底**：Mock 数据只能保 UI，不能保声音；如果现场网络不稳，建议加一首已授权示例音频到 `rawfile`，否则要接受“断网时无音频可播”。
- **卡片登录门禁**：已在上文列为必须修复项。
